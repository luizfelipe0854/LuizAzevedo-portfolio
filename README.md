Portfólio pessoal desenvolvido com tecnologias modernas, apresentando projetos, habilidades e experiências profissionais. Design responsivo e interface intuitiva seguindo as melhores práticas de desenvolvimento front-end.

## 🚀 Tecnologias

- **React 19.1.0**: Biblioteca JavaScript para construção de interfaces
- **Vite 5.4.10**: Build tool e dev server para desenvolvimento ágil
- **Tailwind CSS v4**: Framework CSS utility-first para estilização moderna
- **React Icons**: Biblioteca de ícones para React
- **Swiper**: Biblioteca para criação de carrosséis interativos

## 🏗️ Arquitetura

O projeto segue o padrão Atomic Design para uma estrutura escalável e manutenível:

### Atoms

- `Button`: Componente base para botões
- `IconLink`: Links com ícones integrados
- `Input`: Campos de entrada padronizados
- `ScrollToTop`: Navegação rápida ao topo
- `Title`: Títulos consistentes

### Molecules

- `ContactForm`: Formulário de contato
- `ProjectCard`: Cards para exibição de projetos
- `SkillIcon`: Ícones de habilidades técnicas
- `Timeline`: Linha do tempo para experiências

### Organisms

- `About`: Seção de apresentação pessoal
- `Header`: Navegação principal responsiva
- `Hero`: Seção de destaque inicial
- `Projects`: Galeria de projetos com carrossel mobile
- `Skills`: Grade de habilidades técnicas
- `WorkExperience`: Histórico profissional

## 🎨 Design System

- Sistema de cores customizado via variáveis CSS
- Layout responsivo com breakpoints Tailwind
- Tipografia consistente
- Componentes reutilizáveis

## 🚦 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/luizfelipe0854/LuizAzevedo-portfolio.git
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

4. Acesse `http://localhost:5173` no seu navegador

## 📱 Recursos Responsivos

- Layout adaptativo para dispositivos móveis, tablets e desktop

- Carrossel de projetos em visualização mobile
